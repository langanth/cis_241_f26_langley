# CIS-241 Midterm Study Guide

## General Topics
- Basic Linux Commands
- Git
- Bash
- Regex

## Linux Commands
For the midterm, you should be familiar with basic Linux commands that can be found on the cheat sheet. Students should be able to demonstrate knowledge of the following:
- General navigation
- Familiarity of basic concepts for reading files
- Familiarity of manipulating files
- Familiarity of transferring files from one machine to another
- Familiarity of SSH
- Familiarity of basic compression using gzip, bzip, and tar

## Git
Students should be able to do each of the following tasks using git:
- Creating/Initializing a repo
- tracking, staging, and committing files
- pushing or pulling from remote sources
- manage multiple branches
- handle basic merge conflicts

## Bash
Students should be able to use basic bash scripts including the following:
- Creating a basic bash file
- Using arguments
- Using conditionals
- Using loops
- Using functions

## Regex
Students should be able to implement some basic usage of regex
- utilize special characters in strings
- use ERE in grep
